A tiny model-free Python program that writes one original haiku about debugging — five, seven, five syllables — to /output/entry.txt for make.fun's "Seventeen Syllables of Debugging" bounty.

The haiku it writes: a red breakpoint waits — cursor blinks at three a.m. — the bug was me, friend.

## Run it

```sh
python3 main.py
```
